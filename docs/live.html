One box. Paste a public X post about a memecoin and read the trained next-day direction forecast. The model runs in your browser: nothing is uploaded, and no server is involved.

No demonstrated forecasting edge. This live model uses the wording of the post plus the coin; on held-out data it scores 41.21% on later dates and 50.22% on coins excluded from training, against a coin-only baseline of 51.18% and 55.84%. A bullish-sounding post is not a reliable price forecast, and no forecast here is financial advice.
What this page runs, exactly. The submitted model adds a frozen FinTwitBERT sentiment block, which needs the Colab runtime and cannot run in a static page. This page runs the identical wording + coin pipeline without that block, trained on the same 991 batches (556 coin-days, 1-28 posts per batch) with the same coin-day weighting and target: Next full UTC day after snapshot cutoff, close > open; flat is not up. Word contributions are multiplied out from the fitted vocabulary, so they explain this model rather than the effect a post had on a price.
